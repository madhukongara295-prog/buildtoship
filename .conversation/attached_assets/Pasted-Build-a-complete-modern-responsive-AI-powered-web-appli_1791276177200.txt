Build a complete, modern, responsive, AI-powered web application called:

"AgriCycle – Agricultural Waste Marketplace"

IMPORTANT:
This project is based on the following official problem statement:

"Build a platform where farmers can list agricultural waste such as straw, husks, and crop residues so industries can purchase and reuse them."

The main goal is to create a working prototype that connects FARMERS who have agricultural waste with INDUSTRIES/BUYERS who need agricultural waste.

The application should look like a professional startup product, not a basic college CRUD project.

====================================================
1. CORE IDEA
====================================================

Create a two-sided agricultural waste marketplace.

Farmers can:
- Register/login
- Create agricultural waste listings
- Upload photos of their waste
- Use AI to identify the waste type from the image
- Enter or estimate quantity
- Get AI-based suggested pricing
- Add location
- View nearby buyers
- Receive offers from industries
- Accept/reject offers
- Arrange pickup
- Track orders
- Track earnings
- View sales history
- Receive notifications

Industries/Buyers can:
- Register/login
- Search agricultural waste
- Filter by waste type, quantity, price and location
- View waste listings
- See farmer/location information
- Make an offer
- Purchase waste
- Arrange pickup
- Track orders
- View purchase history

The platform should help:
1. Farmers earn additional income from agricultural waste.
2. Industries get agricultural raw materials easily.
3. Reduce agricultural waste burning.
4. Promote recycling and circular economy.
5. Reduce unnecessary transportation by connecting nearby farmers and industries.
